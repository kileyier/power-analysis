## 📈 过去十年发生了什么大事？

三家公司的利润波动都很大，主要是因为**煤价**。煤价涨，火电公司就亏钱；煤价跌，火电公司就赚钱。

### 关键年份回顾

| 年份 | 大事 | 对三家公司的影响 |
|------|------|----------------|
| 2015-2016 | 煤价低位 | 三家公司都赚得不错 |
| 2017-2018 | 煤价大涨 | 利润大幅下滑 |
| 2021 | 煤价暴涨到历史高点 | **国电亏了20亿，浙能亏了8亿**，只有华能蒙电（有自产煤）赚了4.5亿 |
| 2022 | 电价涨了20%+煤价回落 | 开始回暖 |
| 2023-2024 | 煤价低位+新能源发力 | 利润创近十年最高 |
| 2025 | 电价开始下降 | 利润都有所下滑 |
| 2026+ | 水电/核电/风电新项目投产 | 成长故事开始兑现 |

### 一张图看懂：煤价暴涨时谁扛住了？

## 🔍 每家公司的"杀手锏"

### 国电电力(600795) — 未来靠水电

```
最大看点：大渡河流域水电站
├─ 2026年起新水电站陆续投产
├─ 水电一度电成本只要几分钱，利润极厚
└─ 承诺2024-2026年分红≥60%
```

- **优势**: 体量大、业务全、分红承诺明确
- **风险**: 负债高(73%)、水电建设可能延期

### 浙能电力(600023) — 未来靠核电

```
最大看点：参股核电站
├─ 三门核电二期2026年投产
├─ 核电利润稳定，不受煤价影响
└─ 负债低(41%)，最安全
```

- **优势**: 负债最低、分红历史好、核电成长期权
- **风险**: 火电占比太高(85%)、转型速度偏慢

### 华能蒙电(600863) — 未来靠风电

```
最大看点：内蒙古风电
├─ 2025年注入160万千瓦风电资产
├─ 内蒙古风大，风机转得比别人多20%
└─ 自己有煤矿，火电成本比别人低
```

- **优势**: 煤电一体化成本低、风电禀赋全国第一、负债低
- **风险**: 市值小(320亿)流动性差、业务集中在内蒙古

## ⚠️ 投资风险（必须知道）

### 最大的三个风险

1. **电价下降** 🔴
   电力市场改革后电价竞争加剧，三家都在受影响。2025年已经开始降价了。

2. **煤价反弹** 🟡
   如果煤价又涨回去，火电利润会大幅缩水。不过现在煤价处于下行周期，风险可控。

3. **新能源不达预期** 🟡
   水电/核电/风电项目建设周期长，如果延期投产，成长故事要推迟。

### 各家的"软肋"

| 公司 | 最怕什么 |
|------|---------|
| 国电电力 | 负债率高，加息周期利息支出增加 |
| 浙能电力 | 火电占比高，转型速度跟不上 |
| 华能蒙电 | 盘子小，股价波动大 |
