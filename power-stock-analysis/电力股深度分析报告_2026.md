## 2. 行业背景与宏观环境

### 2.1 中国电力行业格局

2025年中国电力行业核心数据：
- **全国发电装机容量**: 突破35亿千瓦
- **风光装机**: 连续第三年超过煤电装机（"三连超"）
- **可再生能源发电量占比**: 全社会用电量中约40%来自可再生能源
- **火电利用小时数**: 持续下降趋势，2024年约4300小时

### 2.2 关键政策与趋势

| 趋势 | 影响 |
|------|------|
| **"双碳"目标推进** | 火电从主力电源→调节性电源转型，长期碳税风险 |
| **煤价中枢下移** | 2023年后煤价回落，火电盈利修复显著 |
| **电价市场化** | 电力现货市场建设加速，电价波动加大 |
| **新能源平价上网** | 补贴退坡，竞争加剧，但绿电交易溢价显现 |
| **容量电价机制** | 火电获容量补偿，稳定基础收益 |

### 2.3 火电板块投资逻辑（2026年视角）

1. **防御属性**: 火电估值处于历史低位（PE 8-12x），高股息提供安全垫
2. **周期弹性**: 煤价下行→火电盈利弹性巨大（度电成本敏感）
3. **转型期权**: 新能源装机增长提供长期成长性
4. **调峰价值重估**: 火电作为电网调峰资源的价值正在被重新定价

## 3. 公司基本面深度分析

### 3.1 国电电力(600795.SH)

#### 公司概况

| 项目 | 内容 |
|------|------|
| 控股股东 | 国家能源投资集团（央企） |
| 主营业务 | 火电、水电、风电、光伏发电及热力 |
| 总装机容量 | ~1.1亿千瓦（含在建） |
| 上市时间 | 1997年 |
| 员工人数 | ~3.5万人 |

#### 业务结构

```
火电 ~65% | 水电 ~20% | 风电 ~10% | 光伏 ~5%
```

国电电力是国家能源集团旗下核心电力上市平台，业务覆盖火、水、风、光全电源类型，是中国最大的综合性电力上市公司之一。

#### 核心竞争优势

1. **大渡河流域水电**: 独享大渡河流域开发权，2026年起新机组集中投产，水电装机将从当前的~1800万千瓦提升至~2800万千瓦（远期），是未来5年最确定的成长驱动力
2. **高股息承诺**: 明确承诺2024-2026年分红比例不低于60%，在电力股中属顶级
3. **央企信用背书**: 融资成本低，抗风险能力强
4. **全电源布局**: 火电（调峰+基荷）+水电（低成本基荷）+新能源（成长），结构均衡

### 3.3 内蒙华电/华能蒙电(600863.SH)

#### 公司概况

| 项目 | 内容 |
|------|------|
| 控股股东 | 北方联合电力/中国华能集团（央企） |
| 主营业务 | 火电、供热、风电、太阳能、煤炭 |
| 总装机容量 | ~1,500万千瓦 |
| 上市时间 | 1994年（内蒙古首家上市公司） |
| 所在地 | 内蒙古自治区 |
| 2025年更名 | 内蒙华电 → 华能蒙电 |

#### 业务结构

```
火电 ~70% | 风电 ~20% | 煤炭 ~8% | 光伏 ~2%
```

华能蒙电是内蒙古区域电力龙头，最大的特色是"煤电一体化"——自有煤矿（魏家峁煤矿）供应部分电煤，在煤价高涨时具备独特成本优势。2025年完成160万千瓦风电资产注入后，新能源装机跃升至362.62万千瓦。

#### 核心竞争优势

1. **煤电一体化**: 自产煤成本低于市场价，火电盈利稳定性优于纯火电公司
2. **风电资源禀赋**: 内蒙古是全国风电资源最优区域，利用小时数高，项目IRR领先
3. **新能源转型加速**: 2025年注入160万千瓦风电，未来规划新能源装机占比超50%
4. **分红历史长**: 上市以来累计分红26次，总金额116.09亿元

## 9. 附录：关键名词解释

| 名词 | 解释 |
|------|------|
| **PE(市盈率)** | 股价÷每股收益，越低越"便宜"。火电股通常8-15倍 |
| **PB(市净率)** | 股价÷每股净资产，<1表示股价低于净资产 |
| **ROE(净资产收益率)** | 净利润÷净资产，衡量股东回报效率 |
| **股息率** | 每股分红÷股价，越高分红越多 |
| **扣非净利润** | 扣除非经常性损益后的净利润，更能反映真实经营 |
| **利用小时数** | 发电设备年平均满负荷运行小时数，衡量设备效率 |
| **长协煤** | 长期协议煤炭供应，价格低于市场价 |
| **容量电价** | 按发电容量支付的固定费用，保障火电基础收入 |
| **绿电交易** | 绿色电力单独交易，通常有溢价 |
| **碳交易** | 碳排放配额交易，火电企业需购买碳配额 |
