## 1. 煤电联动逻辑

### 1.1 煤价 → 电力股利润的传导链

```
煤价上涨 ──→ 火电成本上升 ──→ 火电利润压缩 ──→ 电力股下跌
                                              ↑
煤价下跌 ──→ 火电成本下降 ──→ 火电利润释放 ──┘

煤价上涨 ──→ 煤炭股利润上升 ──→ 煤炭股上涨
                                              ↓
煤价下跌 ──→ 煤炭股利润下降 ──→ 煤炭股下跌 ─┘
```

**核心规律**: 煤价与电力股**反向**、与煤炭股**同向**。煤价涨→煤炭股涨、电力股跌；煤价跌→煤炭股跌、电力股涨。

### 1.2 2026年当前所处周期位置

| 变量 | 当前状态 | 趋势 |
|------|---------|:---:|
| 煤价(动力煤) | 持续下行周期 | 🔻 |
| 电价(市场化) | 温和下降 | 🔻 |
| 火电利润 | 煤价跌幅>电价跌幅，利润空间扩大 | ✅ |
| 煤炭股盈利 | 2025年见底，2026Q1边际改善 | ➡️ |

### 1.3 投资启示

```
煤价下行期 → 优先配置 电力股（成本下降逻辑）
煤价上行期 → 优先配置 煤炭股（涨价逻辑）
震荡期    → 配置 煤电一体标的（对冲逻辑）
```

**当前判断**: 煤价处于低位下行周期，**整体偏向电力股优于煤炭股**。但部分煤炭龙头的超高股息率提供了安全垫。

## 4. 煤电对冲组合策略

### 4.1 煤价周期 vs 配置策略

```
煤价走势       ↑ 上涨期         ↓ 下跌期         ➡ 震荡期
──────────────────────────────────────────────────────────
推荐方向       煤炭股占优       电力股占优       煤电平衡
煤炭股配置      70%              30%              50%
电力股配置      30%              70%              50%

当前(2026.6): 煤价低位 → 偏电力股
```

### 4.2 最佳对冲组合

**组合思路**: 用煤炭股的高股息作为"稳定器"，电力股的周期弹性作为"进攻器"。

| 角色 | 标的 | 逻辑 |
|------|------|------|
| 🛡️ 稳定器 | 中国神华 30% | 6.5%股息率打底，煤价跌时神华非煤业务(电力+铁路)提供缓冲 |
| ⚔️ 进攻器 | 国电电力 30% | 煤价下行受益最大，水电投产成长性最强 |
| 🏗️ 弹性仓 | 华能蒙电 20% | 煤电一体化+风电弹性，煤价跌时相对受益 |
| 💰 收益仓 | 陕西煤业 20% | 高股息+低成本，周期底部安全边际高 |

**预期年化回报**: 8-15%（含股息）
